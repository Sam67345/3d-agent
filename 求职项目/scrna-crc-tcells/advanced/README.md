# advanced/ —— 单细胞进阶分析模块（加分章节）

本目录是主项目（GSE108989 结直肠癌 T 细胞 Seurat 分析，见上级目录 01/02 脚本）的配套**进阶加分内容**。主项目完成"质控 → 分群 → 注释 → 差异表达"的基础叙事；这里的三个模块在此基础上回答三个更深的生物学问题，对应论文里的高阶图。

## 三个模块的定位：各讲什么生物学故事

| 模块 | 脚本 | 生物学故事 | 对应论文图 | 前置条件 |
|---|---|---|---|---|
| 拟时序 | `04_monocle3_trajectory.R` | **分化轨迹**：T 细胞不是静止的一群群细胞，而是沿着"初始/记忆 → 效应 → 耗竭"的方向动态分化。肿瘤微环境把 T 细胞推向耗竭终点。Monocle3 在 UMAP 上拟合分化树，给每个细胞一个"拟时序"坐标。 | Zhang et al. *Nature* 2018（GSE108989 出处）中的 T 细胞轨迹图 | 主项目 01 输出的带注释 Seurat 对象（.rds） |
| 细胞通讯 | `05_cellchat_communication.R` | **细胞互作**：T 细胞的耗竭不是自己发生的——肿瘤/髓系/基质细胞通过配体-受体信号（MIF–CD74、TIGIT–PVR 等检查点通路）主动抑制它。CellChat 推断"谁给谁发什么信号"。 | 论文中的 cell-cell communication 网络图 / 气泡图 | 含**多种细胞类型**注释的 Seurat 对象（只有 T 细胞时结论受限，脚本内有解决方案） |
| CNV 推断 | `06_infercnv_malignant.R`【可选·高阶】 | **恶性判定**：肿瘤细胞带着基因组拷贝数异常（染色体臂级扩增/缺失），正常细胞没有。inferCNV 从表达数据反推 CNV，把"恶性上皮细胞"从混合细胞中挑出来。 | 肿瘤单细胞论文的 inferCNV 全基因组热图 | ⚠️ GSE108989 几乎不含上皮细胞，**本模块需换用含上皮的数据集**（如 GSE132465）才能启用 |

三个模块合起来是一条完整的故事线：
**微环境中的恶性细胞与免疫细胞互作（06 鉴定恶性 → 05 互作网络）→ 共同把 T 细胞推向耗竭（04 分化轨迹）**——这正是 GSE108989 那篇 *Nature* 论文的核心叙事。
