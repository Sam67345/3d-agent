# 学习手册 · scrna-crc-tcells

> 用法：对照代码逐段阅读。每段含 ①做什么 ②核心概念一句话 ③面试自测题（附参考答案要点）④深入关键词。

---

## 段落 1：数据获取与读入（`01_qc_clustering.R` 第 0–1 节）

**① 做什么**：从 GEO 下载 GSE108989 的 TPM 表达矩阵（GEOquery 自动下载或手动下载），用 `data.table::fread` 读成"行=基因、列=细胞"的矩阵。

**② 核心概念**：
- **Seurat 对象结构**：一个"大盒子"——`counts`（原始矩阵）、`data`（标准化后）、`meta.data`（每个细胞的注释表）、`reductions`（PCA/UMAP 坐标）分层存放。
- **Smart-seq2 vs 10x**：Smart-seq2 测全长转录本、无 UMI、每细胞基因数多（~8000），结果通常是 TPM；10x 测 3' 端、有 UMI 去重、每细胞基因数少（~2000），结果是 count。

**③ 面试自测**
1. *"这个矩阵的行和列分别是什么？TPM 和 count 区别在哪？"*
   答：行=基因、列=细胞。TPM 是长度归一化的相对丰度（可直接跨样本比较但非整数计数）；count 是 UMI 原始计数（更适合统计建模）。
2. *"为什么用 fread 不用 read.csv？"*
   答：矩阵上万列 × 两万行，read.csv 可能要几十分钟且内存翻倍；fread 多线程快 10 倍以上。
3. *"GEOquery 下载相比手动下载有什么优势？"*
   答：可复现性——别人 clone 仓库后一条命令拿到同样数据；避免手动操作出错。

**④ 深入关键词**：GEO supplementary files、TPM vs FPKM vs CPM、`SeuratObject` assay 结构

## 段落 2：质控（`01` 第 2–3 节）

**① 做什么**：创建 Seurat 对象；计算线粒体基因比例；按 nFeature（1000–12000）、percent.mt（<10%）过滤低质量细胞和双细胞。

**② 核心概念**：
- **Smart-seq2 vs 10x 质控差异一句话**：Smart-seq2 测序深，nFeature 阈值整体"上移"（下限 1000、上限 12000），10x 常用 200–5000；两者都用线粒体比例识别濒死细胞。
- 线粒体比例高 = 细胞膜破损，胞质 mRNA 流失，mtRNA 相对富集 → 濒死/低质细胞。

**③ 面试自测**
1. *"你的 QC 阈值怎么定的？为什么不是 10x 那套？"*
   答：Smart-seq2 每细胞检出 5000–10000 基因，用 10x 的 5000 上限会误删真实高质量细胞；下限 1000 去空孔/碎片，上限 12000 防双细胞，mt<10% 因组织消化细胞比 PBMC 应激更强。
2. *"percent.mt 高说明什么？有没有例外？"*
   答：通常说明细胞破损濒死；例外是代谢极度旺盛的细胞（如某些肿瘤细胞/活化淋巴细胞）天然 mt 偏高，需结合 nFeature 判断。
3. *"怎么判断阈值合不合理？"*
   答：画过滤前后小提琴图看分布，阈值应切在分布尾部而非主峰；也可看 nFeature vs percent.mt 散点。

**④ 深入关键词**：doublet detection（DoubletFinder）、ambient RNA（SoupX）、QC 分布诊断

## 段落 3：标准化 / HVG / PCA / UMAP（`01` 第 4–6 节）

**① 做什么**：LogNormalize 消除测序深度差异 → 选 2000 个高变基因 → ScaleData 标准化并回归 mt 影响 → PCA 线性降维（选前 20 PC）→ Louvain 聚类 → UMAP 可视化。

**② 核心概念**（每条一句话直觉）：
- **标准化**：把每个细胞缩放到同一"总表达预算"，让比较的是表达比例而非测序量。
- **HVG**：只保留变化大的基因，因为它们才携带区分细胞类型的信息，其余是噪音。
- **PCA**：把 2 万维基因空间压成几十个"最大方差方向"，保留主要信息、丢弃噪音。
- **UMAP**：非线性降维，把 PC 空间压到 2D 画图；注意它只用于"看"，聚类是在 PC 空间做的。

**③ 面试自测**
1. *"为什么聚类用 PCA 结果而不是 UMAP 坐标？"*
   答：UMAP 为可视化牺牲了全局距离保真，点间距离不代表真实相似度；PCA 保留全局结构，适合距离敏感的聚类。
2. *"PC 个数怎么选？"*
   答：ElbowPlot 找拐点，拐点后每个 PC 贡献的方差趋平；本数据集取 20，兼顾信息保留与去噪。
3. *"resolution 参数调大调小会怎样？"*
   答：调大→cluster 变多变细，可能拆出生物学上无意义的亚群；调小→可能把不同亚型合并。需要对照 marker 基因验证。

**④ 深入关键词**：SNN graph、Louvain/Leiden 算法、UMAP vs t-SNE、批次效应（Harmony）

## 段落 4：Marker 基因与亚型注释（`01` 第 7–8 节）

**① 做什么**：`FindAllMarkers` 找每个 cluster 相对其余细胞高表达的基因（Wilcoxon 检验）；画热图与 FeaturePlot；按 CD4/CD8A/CD8B/FOXP3/IL2RA/MKI67 等经典 marker 规则注释 CD4 T、CD8 T、Treg、增殖型。

**② 核心概念**：
- **FindAllMarkers**：单细胞差异检验本质是"一群细胞 vs 其余"，Wilcoxon 秩和检验不假设分布，最稳健常用。
- **BH 校正**：同时检验 2 万个基因会产生大量假阳性，Benjamini-Hochberg 控制 FDR（错误发现率）在 5%，`p_val_adj` 列就是校正后的值，筛基因必须用它。

**③ 面试自测**
1. *"为什么注释 CD8 要看 CD8A 和 CD8B 两个基因？"*
   答：CD8 是 αβ 异二聚体；NK 细胞也表达 CD8A 但不表达 CD8B，单看 CD8A 会把 NK 误判为 CD8 T。
2. *"p_val 和 p_val_adj 用哪个筛 marker？为什么？"*
   答：必须用 p_val_adj（BH 校正后）。2 万次检验即使全为阴性也期望约 1000 个 p<0.05 的假阳性，FDR 校正控制的是"筛出的阳性中假阳性的比例"。
3. *"自动规则注释可靠吗？"*
   答：只是初稿。必须对照 FeaturePlot、marker 表和文献人工复核；更严谨的做法是用 SingleR 等参考映射工具交叉验证。

**④ 深入关键词**：SingleR / CellTypist 自动注释、Treg 可塑性、FOXP3 的 scRNA 检出率问题

## 段落 5：功能评分（`02_functional_scoring.R` 第 1–3 节）

**① 做什么**：用 `AddModuleScore` 计算每个细胞的细胞毒性评分（GZMA/GZMB/PRF1/NKG7/GNLY）与耗竭评分（PDCD1/HAVCR2/LAG3/TIGIT/TOX/CTLA4），UMAP 展示 + 亚群箱线图 + Kruskal-Wallis / 两两 Wilcoxon+BH 检验。

**② 核心概念**：
- **AddModuleScore 原理**：目标基因集平均表达 − 表达量匹配的随机对照基因集平均表达，得到"相对富集"分数，校正测序深度差异。
- **生物学含义**：细胞毒性 = T 细胞杀伤肿瘤的武器（颗粒酶/穿孔素）；耗竭 = 长期抗原刺激后"武器哑火、刹车全开"（PD-1 等检查点上调、TOX 驱动），是肿瘤免疫治疗（PD-1 抗体）的核心靶点。

**③ 面试自测**
1. *"为什么不用目标基因平均表达直接比，要用 AddModuleScore？"*
   答：直接平均会被测序深度/整体表达水平混淆；模块分数减去匹配对照集的背景，得到的是相对富集，细胞间可比。
2. *"多组比较为什么用 Kruskal-Wallis 而不是 ANOVA？"*
   答：模块分数分布通常偏态且方差不齐，Kruskal-Wallis 基于秩次、不假设正态，更稳健。
3. *"耗竭 CD8 T 和细胞毒性是互斥的吗？"*
   答：不是。肿瘤中常见"耗竭但仍有部分细胞毒性"的过渡状态，两者可同高；这也是耗竭不是简单"关闭"而是独特分化状态的证据。

**④ 深入关键词**： exhaustion trajectory（拟时序 Monocle3）、TOX 与染色质重塑、免疫检查点阻断（ICB）

## 段落 6：差异表达 + GO/KEGG 富集（`02` 第 4–5 节）

**① 做什么**：CD8_T vs Treg 差异表达（Wilcoxon）画火山图；取显著上调基因用 clusterProfiler 做 GO（BP）与 KEGG 富集，画气泡图。

**② 核心概念**：
- **clusterProfiler**：把"一堆差异基因"翻译成"哪些生物学过程/通路被富集"，核心是超几何检验 + BH 校正。
- 富集 ≠ 差异表达：先看"哪些基因变了"，再问"这些基因集中在哪些功能上"。

**③ 面试自测**
1. *"GO 富集的统计学原理是什么？"*
   答：超几何检验——在"某 GO 条目注释的 N 个基因"中，我的差异基因列表抽到 k 个是否显著多于随机期望；再做 BH 校正。
2. *"为什么要 bitr 转换 ID？"*
   答：富集数据库用 Entrez ID 建索引，而我们的基因列表是 Symbol；ID 转换会丢失少量无对应关系的基因，属正常。
3. *"气泡图上 GeneRatio、点大小、颜色各代表什么？"*
   答：GeneRatio=富集到的差异基因数/该条目总基因数；点大小=富集到的基因数；颜色=FDR 显著性。

**④ 深入关键词**：GSEA（不依赖阈值）、ORA vs GSEA、pseudobulk 差异分析（DESeq2）

## 段落 7：LIS 谱系评分（`03_lis_score.py`）

**① 做什么**：读 mtDNA 变异 VAF 矩阵（行=变异、列=细胞），计算每个变异 LIS = Mean(VAF)/(1+Var(VAF))，LIS≥0.6 判定为可信谱系标记；`--demo` 生成模拟数据自测。

**② 核心概念**：
- **LIS 公式**（Wang et al., Genome Biology 2025）：均值高 = 变异真实存在；方差小 = VAF 稳定、符合"一次突变被克隆遗传"；+1 防除零并把分数压进 (0,1)。
- **生物学动机**：mtDNA 突变是"天然条形码"——克隆扩增的 T 细胞共享同一祖先的 mtDNA 突变，可替代/补充 TCR 谱系追踪。

**③ 面试自测**
1. *"LIS 公式为什么分子是均值、分母含方差？"*
   答：均值奖励"广泛且高强度存在"的变异；方差惩罚 VAF 波动大的变异（多半来自测序噪音或多位点事件）；二者比值恰好刻画"稳定可遗传的谱系标记"。
2. *"缺失值为什么填 0 而不是删掉该细胞？"*
   答：mtDNA 变异检测中"未检测到"通常就是 VAF=0（无该突变），删细胞会丢失"哪些细胞不携带"这一关键信息。
3. *"demo 自测验证了代码的什么性质？"*
   答：构造了已知的 3 个高均值低方差"真标记"和噪音/稀有变异，断言 Top3 全部被识别，验证公式实现方向正确、阈值行为符合预期。

**④ 深入关键词**：VAF（variant allele frequency）、异质性（heteroplasmy）、MQuad/mgatk、TCR-mtDNA 联合谱系追踪

## 附：一键复习清单

| 概念 | 一句话 |
|---|---|
| Seurat 对象 | counts/data/meta.data/reductions 分层的大容器 |
| Smart-seq2 vs 10x | 全长深测 TPM vs 3' 端 UMI count，QC 阈值随之上移 |
| LogNormalize | 消除深度差异，比的是表达比例 |
| HVG/PCA/UMAP | 挑信息基因 → 线性压缩去噪 → 仅用于画图 |
| AddModuleScore | 目标集均值 − 匹配对照集均值 |
| 耗竭 vs 细胞毒性 | 刹车上调功能衰减 vs 杀伤武器库；可同时高 |
| BH 校正 | 控制 FDR，多检验必须看 adjusted p |
| clusterProfiler | 差异基因 → 超几何检验富集功能 |
| LIS | Mean/(1+Var)，mtDNA 天然条形码的可靠性评分 |
